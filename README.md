# XnX Player

一款为 Windows 打造的桌面影视播放器。

它的界面不是 PlayStation 5 主题的复刻，而是把三种东西组合在一起：**ps5-homebrew-ui 的动效与组件手感**、**Plex 的信息架构与海报墙布局**、以及 **TMDB 作为首页的数据支撑**。你看到的是一个以电影海报为主角、焦点会在组件之间滑动的媒体中心，而不是一张文件列表。

播放由 mpv 内核完成，支持 HDR 直通、硬件解码、多音轨/多字幕、章节、倍速、统计面板与片头片尾跳过。

## 安装与数据位置

发布产物有两种形式：

- **安装包** `XnX-Player-Setup-<version>.exe`：安装向导会先显示使用许可与安装说明，可以更改安装目录，默认装在当前用户目录下，不需要管理员权限。
- **便携版** `XnX-Player-Portable-<version>.zip`：解压即可运行，数据保存在程序目录的 `userdata` 文件夹，整个目录可以随身携带。

安装时可以为数据目录选择三种方式：

1. **默认位置**：`%APPDATA%\XnX Player`
2. **程序目录下的 `userdata`**：等价于便携版的数据布局
3. **自定义目录**：任意可写路径

数据目录保存 `state.json`、日志（`log/`）、截图（`screenshots/`）与片头片尾标记（`segments.json`）；更新和卸载都不会删除它。安装版写入的 `data-dir.txt` 与便携包中的同名文件决定数据位置：写 `default` 用 `%APPDATA%\XnX Player`，写相对路径相对程序目录，写绝对路径则原样使用。

程序目录另带许可文件：`LICENSE.txt`（本程序）、`THIRD_PARTY_NOTICES.md`（播放内核与界面素材的第三方说明）、`licenses/`（GPL-2.0 / LGPL-2.1 / LGPL-3.0 全文）与 `libmpv-SOURCE.txt`（这个安装包实际使用的 mpv 构建版本与许可）。

发布通道与产物：

| 通道 | 来源 | 产物 |
|---|---|---|
| dev | beta 分支每次构建 | 便携版 zip（Actions 产物，不进入 Release） |
| beta | dev 验证后手动晋升 | 便携版 zip + 安装包 |
| stable | beta 验证后合并、手动晋升 | 便携版 zip + 安装包 |

应用内更新始终使用便携版 zip：stable/beta 从 Release 资产下载，dev 从 Actions 产物下载，因此 dev 通道需要在系统环境变量中配置 `XNX_GITHUB_TOKEN`。更新只替换安装目录里的程序文件，跳过数据目录与 `data-dir.txt`。

## 首页：像流媒体，而不是文件管理器

打开应用，首页由 TMDB 提供内容：正在上映、热门电影、热门剧集、正在播出、即将上映、本周趋势。每张海报都来自 TMDB，点开就能看到简介、评分、题材与演职员。

真正要播放时，XnX Player 会去你已配置的媒体源里找对应文件：

- **电影和剧集可以来自本地文件夹、Emby、Jellyfin、WebDAV、OpenList/AList 或 IPTV。**
- 同一部片在多个来源都有文件时，详情页会列出“播放来源”，你可以选择从本地、Emby 或 WebDAV 播放。
- 只有 TMDB 信息、没有任何来源文件的条目也会正常展示；进入详情页会明确提示“缺少媒体源”，不会给你一个点不动的播放按钮。

首页顶部可以切换“全部来源”或某个具体来源：

- **全部来源**：TMDB 聚合首页，适合发现新片和统一入口。
- **某个来源**：只展示这个来源自己的内容与分类，例如 Emby 的继续观看、最近添加、收藏与剧集；本地文件夹则展示扫描到的影片。

主视觉支持自动轮播，也可以用手柄/方向键切换；题材胶囊可以按类型浏览当前首页的内容。

## 详情页

- TMDB 海报、背景图、标题、年份、评分、题材、简介与演职员。
- 本地文件额外显示文件信息：大小、容器、分辨率、视频编码、位深、音频、HDR、帧率、修改时间与所在目录。
- 剧集/季显示剧集列表；从列表起播会整季加入播放队列，播完自动下一集。
- 多个来源可用时可切换“播放来源”；切换后播放路径、技术信息与剧集列表会一起更新。
- 没有匹配到文件时显示“缺少媒体源”，并说明如何补上。

## 播放体验

- HDR 直通、硬件解码、去色带、画面比例与色彩调整。
- 音轨、字幕（含外挂字幕）、章节、倍速、循环、A-B 循环、播放列表。
- 统计面板：分辨率、编码、位深、色彩空间、解码方式、帧率、丢帧、音频参数、码率等。
- 片头片尾按章节名识别，也可以手动标记（Alt+N / Alt+E）；按完整路径记忆，可自动跳过。
- 书签：Ctrl+B 在当前位置记一个点（再按一次取消），进度条上有金色刻度，菜单里可跳转或清空。
- 旁挂剪辑表：同目录的 `<视频>.edl`（Kodi 格式，时间按毫秒）与 comskip 的 `<视频>.txt`
  （帧号，帧率取自文件首行）会被自动读取，广告段直接跳过；支持 cut / mute / 广告三种动作。
- 音乐文件没有视频轨时进入音乐模式，不再黑屏。
- 播放控制条、菜单与提示都支持鼠标：悬停高亮、点击执行、滚轮调音量、右键打开“更多”。
- HDR 开启时，常驻控制条仍保持 SDR 的清晰度；菜单与提示会做亮度补偿。

## 媒体源

在 **媒体库 → 添加来源** 中选择：

| 来源 | 适合的场景 |
|---|---|
| 本地文件夹 | 已经整理好的电影/剧集目录 |
| Emby / Jellyfin | 已有媒体服务器与元数据 |
| WebDAV | NAS、网盘或远程目录 |
| OpenList / AList | 挂载网盘后的统一目录 |
| IPTV | m3u 播放列表与 XMLTV 节目单 |
| TMDB | 只提供首页与详情数据，不提供文件 |

### 配置 TMDB

1. 在 [TMDB](https://www.themoviedb.org/settings/api) 申请 API Key（v3 Key 或 v4 Read Access Token 均可）。
2. 打开 **媒体库 → 添加来源 → TMDB**，填入 Key 保存。
3. 回到首页，TMDB 栏目会自动加载。

TMDB 只负责“有什么片、长什么样”；能不能播，取决于你配置的媒体源里有没有对应文件。

## 常见问题

**首页没有 TMDB 内容？**
检查 TMDB Key 是否填写正确、网络是否能访问 `api.themoviedb.org`。应用日志在数据目录的 `log/app.log`：默认是 `%APPDATA%\XnX Player\log\app.log`，便携版在程序目录的 `userdata\log\app.log`；数据目录不可写时会退回到 `%APPDATA%`。

**TMDB 里有这部片，但提示“缺少媒体源”？**
媒体文件按“标题 + 年份”匹配。请确认来源里存在同名影片，或文件名中的年份与 TMDB 一致；年份缺失时会尝试只按标题匹配。

**同一部片有多个版本？**
详情页的“播放来源”会列出所有可用文件，选择你想播放的那一个即可。

**HDR 下菜单看起来偏暗？**
常驻控制条使用独立的 SDR 绘制层；菜单和提示仍由 mpv 绘制，只做了亮度补偿，因此与 SDR 模式下不会完全一致。

## 已知限制

- 弹幕功能尚未提供。
- ISO 文件会按普通文件交给播放器，未接入蓝光导航。
- 本地文件信息来自文件名与文件属性，不做在线刮削。
- 手柄只覆盖基础导航，复杂菜单仍以键盘/鼠标为主。
- 外挂字幕选择依赖系统文件对话框，播放页需要在前台。
