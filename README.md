# XnX Player

A PlayStation 5–styled desktop media player for Windows, built on Flutter + libmpv.

- **Front end**: a hand-rolled 10-foot UI — 1920×1080 design canvas, geometric focus
  navigation, square tile rails, Control Center dock — modelled on the interaction
  patterns of [Zerk Play 2.0](https://github.com/florinp93/Zerk-Play-2.0).
- **Playback core**: libmpv driven over FFI with a native child window
  (`vo=gpu-next`, `gpu-api=d3d11`, `hwdec=auto-safe`, HDR passthrough), mirroring the
  configuration approach of [mpv-Yaozhi](https://github.com/Yaozhil/mpv-Yaozhi).
- **In-player UI**: because the mpv surface always sits above the Flutter canvas, the
  player OSD is drawn inside mpv as an ASS overlay (`assets/mpv/xnx_osd.lua`).

## Status

Milestone 1 — shell, PS5 home, focus engine, libmpv playback of local files, minimal OSD.
Contents sources beyond local files are stubbed in the Media hub and land in M3/M5.

## Building

There is no local Flutter requirement: the Windows runner is generated by CI and the
release bundle is produced there.

```bash
flutter pub get
dart run tool/fetch_libmpv.dart   # stages third_party/mpv/libmpv-2.dll
flutter build windows --release
```

`libmpv-2.dll` must sit next to `xnx_player.exe` at runtime. CI copies it into the
release folder and uploads the whole folder as an artifact.

To pin a specific mpv build, set the repository variable `MPV_TAG` (a tag from
`zhongfly/mpv-winbuild`). Otherwise the latest LGPL dev build is fetched.

## Layout

```
lib/
  design/       PS5 design tokens (colour, type, motion) + theme
  ui/core/      design-canvas scaling, focus engine, shine
  shell/        top tabs, status cluster, Control Center dock
  pages/        home rails, game hub, media hub, settings
  player/       player page + Lua OSD bridge
  playback/mpv/ libmpv FFI bindings, option table, player, window handle
  data/         unified MediaItem model and (later) source adapters
assets/mpv/     xnx_osd.lua — the PS5-styled OSD drawn inside mpv
```

## Controls

| Key | Action |
| --- | --- |
| Arrows | Move focus |
| Enter / Space | Select |
| Tab | Control Center |
| F1 | Open a local file |
| Esc | Back (exits the player) |
| Space / ← → (in player) | Pause, seek ±10s |
