# 视频播放体验规范

## 1. 播放界面

播放画面应保持最大可用面积。默认隐藏 OSD，用户操作或移动鼠标后短暂显示；手柄/遥控器操作时根据按键语义显示对应控制区域。

## 2. Playback OSD

建议区域：
- 顶部：标题、剧集编号、播放源或播放状态
- 中部：播放/暂停、前后跳转、上一集/下一集
- 底部：TimelineScrubber、已播放/总时长、章节标记
- 辅助：音轨、字幕、倍速、画面比例、更多设置

OSD 应支持淡入淡出、焦点导航、鼠标交互和自动隐藏。用户正在操作菜单时不能自动隐藏。

## 3. 时间轴

TimelineScrubber：
- 显示已播放、缓冲和总时长。
- 支持键盘/手柄逐步跳转和长按连续跳转。
- 可选缩略图预览。
- 支持章节标记。
- 预览图加载失败时不阻断 seek。
- 时间显示格式统一。

## 4. 音轨与字幕

AudioTrackSelector：
- 语言名称、声道数、编码格式、默认/当前标记。
- 轨道信息缺失时显示可理解的 fallback。
- 切换后提供短暂反馈。

SubtitleSelector：
- 关闭字幕、内嵌字幕、外挂字幕。
- 语言、字幕格式、默认/强制标记。
- 字幕延迟、大小、位置、样式等高级选项放在二级设置。
- 字幕设置应能在播放时快速访问。

## 5. 播放信息面板

按需展示：
- 容器格式
- 视频编码、分辨率、帧率、码率
- HDR / Dolby Vision 等能力标识（仅在引擎或媒体元数据确认时显示）
- 音频编码、声道、采样率
- 当前字幕轨道
- 解码方式、硬件加速状态
- 缓冲和渲染统计（诊断模式）

不要把推测值当成真实播放状态。技术信息应区分“文件元数据”和“当前播放管线状态”。

## 6. 播放状态模型

UI 只订阅统一 PlaybackState，不直接依赖具体引擎事件：
- idle
- opening
- buffering
- playing
- paused
- seeking
- completed
- error

状态至少包含 position、duration、buffered ranges、volume、playback speed、selected audio/subtitle tracks、media identity 和 error details。

## 7. 播放结束与连续播放

- 电影结束：提供重播、返回详情、下一条推荐。
- 剧集结束：提供下一集卡片与倒计时（可关闭）。
- 播放队列：显示当前项、后续项和移除/跳过操作。
- 播放状态保存应有节流，避免频繁写盘或频繁请求服务端。
