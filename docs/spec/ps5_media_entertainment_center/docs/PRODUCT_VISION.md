# 产品愿景与体验原则

## 1. 产品定义

打造一个以影视内容为中心、具有主机级系统体验的 Windows 媒体娱乐中心。用户进入应用后首先感受到的是一个完整的内容世界，而不是传统桌面播放器的文件打开对话框。

产品同时覆盖：
- 本地媒体库与网络媒体源
- 电影、剧集、动画、纪录片、短片及个人视频
- 媒体元数据、人物、制作团队、系列和合集
- 沉浸式浏览、搜索、收藏、继续观看与观看历史
- 全屏播放、音轨/字幕/章节与播放状态
- 系统级快捷控制中心、通知和设置

音乐可以作为后续扩展域，不应让音乐播放器的交互模型限制视频媒体体验。

## 2. 设计参考的分工

### PS5 Homebrew UI：系统交互与视觉语言
重点研究：
- Home / Shelf / Hero 的内容组织
- 卡片聚焦、空间导航和焦点缩放
- 玻璃质感面板、层级背景和边缘高光
- 控制中心、弹出面板、通知和设置
- 动画节奏、交互音效、状态反馈

### Emby / Jellyfin / Plex：媒体信息架构
重点研究：
- 海报、背景图、Logo、简介和媒体技术信息
- 电影/剧集/季/集的层级关系
- 人物、演职员、导演、制作公司和关联作品
- 继续观看、最近添加、推荐、收藏与观看状态
- 媒体库筛选、排序、合集和搜索

**不要直接拼接不同产品的 UI。** 借鉴媒体信息结构，统一用 PS5-inspired Design System 呈现。

## 3. 体验原则

1. Cinematic：详情页和首页以大幅背景图、海报和内容信息建立氛围。
2. Discoverable：用户能自然发现相关作品、人物、系列和下一集。
3. Focus-first：手柄/遥控器操作路径清晰，焦点始终可见。
4. Contextual：播放时显示播放相关操作，浏览时显示内容相关操作。
5. Quiet UI：控件按需出现，不长期覆盖画面。
6. Consistent：同一类操作在所有页面具有一致的位置、动效和反馈。
7. Resilient：无海报、无简介、元数据冲突、网络中断时都有合理降级。

## 4. 产品体验指标

建议通过测试验证：
- 用户能否在 3 次方向/确认操作内从首页进入继续观看内容
- 任意弹层关闭后能否恢复原焦点
- 从详情页进入播放、返回详情页时滚动位置和焦点是否保留
- 元数据缺失时页面是否仍然完整
- 键盘、手柄、遥控器和鼠标之间切换是否稳定
- OSD 是否能在不遮挡关键画面的情况下完成常用操作
