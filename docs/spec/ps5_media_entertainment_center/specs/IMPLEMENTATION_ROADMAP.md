# 实施路线与验收标准

## Phase 0：设计审计

任务：
- 对照 ps5-homebrew-ui 实际仓库版本，审计可复用组件、Token、动效和声音资源。
- 记录许可证、第三方素材与代码复用边界。
- 在 Flutter 当前项目中盘点已有主题、路由、状态管理和焦点实现。
- 建立参考截图与组件对照表。

验收：
- 有一份准确的“现有能力 / 缺失能力 / 计划扩展”清单。
- 不凭印象复制未核实的组件或设计参数。

## Phase 1：Design System 与 Shell

任务：
- 提取并落地 Token。
- 建立 Surface、Focus、Button、Card、Dialog、Toast 等基础组件。
- 建立 Focus Manager、Overlay Manager 和输入动作映射。
- 完成主导航和页面恢复机制。

验收：
- 键盘与手柄可完成主要页面导航。
- Overlay 关闭后焦点恢复正确。
- 新旧组件使用同一套焦点和动效规范。

## Phase 2：媒体发现与元数据

任务：
- Home Hero、Media Shelf、Poster Card。
- Movie Detail、Series Detail、Season/Episode。
- Person、Credits、Collections、Related Media。
- 图片缓存、占位、加载与错误态。

验收：
- 电影、剧集、集、人物之间可双向浏览。
- 缺失图片和字段不会破坏布局。
- 从详情页返回时恢复焦点与滚动位置。

## Phase 3：播放体验

任务：
- Playback Engine Adapter。
- OSD、Timeline、音轨、字幕、倍速、章节。
- Next Episode、播放队列、播放状态持久化。
- 播放信息与诊断面板。

验收：
- UI 不直接依赖具体解码器 API。
- 播放状态与引擎状态一致。
- OSD 自动隐藏、焦点导航和菜单操作稳定。

## Phase 4：系统级媒体体验

任务：
- Control Center 媒体卡片。
- 全局音频/字幕入口、通知、下载/扫描状态。
- 设置中心与设备信息。
- 用户偏好、性能模式与减少动态效果。

验收：
- 播放、浏览和设置之间的系统操作一致。
- 控制中心不会与 OSD 功能冲突。
- 低性能模式下仍可保持可用帧率。

## Phase 5：打磨与质量验证

测试矩阵：
- 1080p / 4K 显示器与不同 DPI 缩放
- 鼠标、键盘、手柄
- 长标题、多语言、缺失元数据
- 大型媒体库与快速横向滚动
- 网络慢、断网、图片源失效
- 长时间播放、暂停恢复、连续播放
- HDR/音轨/字幕能力按实际引擎支持验证

最终验收：
- 视觉一致性审查通过
- 关键路径无焦点丢失
- 页面恢复行为稳定
- 大型列表滚动和图片加载性能达标
- 播放控制无明显延迟或状态不同步
